# Divineechidume.github.io

This repository holds the code for my personal website (GitHub Pages).

## Site

- **Entry point**: `index.html`
- **Styles**: `assets/css/styles.css`
- **JS (optional, minimal)**: `assets/main.js` — smooth scroll for anchor links

## Edit the content

- Update the hero copy and section text directly in `index.html`.
- Resources list and other section content live in `index.html`.
- Replace placeholder links (email + socials) in the `#contact` section as needed.

## Local preview

Open `index.html` directly in your browser, or serve the folder with any static server.
